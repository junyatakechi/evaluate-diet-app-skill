# レポートの様式

対象者が読む評価にする。
判断ではなく、見せ方の取り決め。各章に何を言うかは、中核判断の委任表とまだ切り出していない判断の表の判断の答えに従う。

## 出す場所

- 評価の全文を、下の章立てのまま、Markdown で、プロジェクトのフォルダ（.env のある起動フォルダ）直下の `output/` にファイルとして書き出す。`output/` が無ければ作る。
- ファイル名は `diet-process-evaluation_<開始日>_<終了日>.md`（日付は YYYY-MM-DD。評価の期間の初日と最終日）。同じ期間のファイルがあれば、上書きする。
- 評価の本文をチャットに書かない。チャットには、書き出したファイルのパスを伝える。
- 指示者が、2026-11-21 に、評価をチャットではなく、プロジェクトのフォルダの `output/` に Markdown のファイルで書き出すと決めたため。

## 評価の期間

指示者の指定が無ければ、今日までの直近30日。食事の記録・食生活の異常検知の表・活動量の表は、この期間の分を載せる。体重と睡眠は、体重の増減の判断の「使用するデータ期間」を読む。

## 章立て

| 章 | 中身 |
|---|---|
| （サブタイトル） | 何を評価した回か。評価の期間を入れる |
| 良い面 | サブタイトルの次。箇条書きで2つ。まだ切り出していない判断（[references/good-points.md](../references/good-points.md)）の答えに従う |
| 悪い面 | 良い面の次。箇条書きで2つ。中核判断の答えのうち、目標を阻害している事実を、裏付けの数字とともに書く。中核判断の答えと食い違わせない |
| 体重の推移 | 「体重の図」、トレンドの見出しの下に「トレンドの図」の3つ、目標達成までの見積もりの見出しの下に「見積もりの図」を置き、表は置かない。起床時刻をメモアプリの睡眠から取った日があれば、その日数と、精度が落ちることを書く |
| 食生活の異常検知 | 下の「食生活の異常検知の表」の2つ。7日間ごとの異常の見出しの下に「異常の図」を置く。7日間ごとの外食の割合の見出しの下に「外食の割合の図」を置く。判断が見なかった項目（記録の語彙が無かったもの）があれば、項目名を1行で書く |
| 活動量 | 「歩数の図」だけを置き、表は置かない。指示者が、2026-11-21 に、歩数の変化を見るために、折れ線と期間の平均の横線にし、下限の線も残すと決め、表を要らないとした |
| 記録不足の日 | レポートの一番下に置く。下の「記録不足の日の表」 |

- 各図のすぐ下に、図の示唆を箇条書きで置く。何をどう書くかは、図解の中核判断の図の示唆の答えに従う。外食の割合の図に何を比べて入れるかは、まだ切り出していない判断（[references/eating-out-insights.md](../references/eating-out-insights.md)）に従う。
- 悪い面は、端的に指摘する（`減り方が遅い`）。割合を書くときは、何に占める割合かを書く（`食生活の異常検知の件数の9割`）。
- 指示者が、2026-11-21 に、悪い面をこの書き方に直したため。
- 示唆と結論の章は置かない。進捗の良し悪しは、トレンドの図の題で見せる。
- 指示者が、2026-11-21 に、結論と示唆の章をやめ、良い面と悪い面を一番上に置き、示唆は各図の下に書くと決めたため。
- 良い面・悪い面・図の示唆の箇条書きでは、単位の前の数値をコード表記にする（`` 約`1`回/週 ``・`` `-0.76`kg ``・`` `2〜3`回/日 ``）。日付（11/01 など）はコード表記にしない。指示者が、2026-11-22 に、見やすさのために決めたため。
- 文は短くし、表と図で見せられることを文で繰り返さない。理由の説明や一般論の解説は書かない。
- 2つ以上を対比している箇所は、箇条書きにせず表にする。会話の逐語のコピーはしない。
- 指示者が、2026-11-21 に、評価の文字が多すぎると指摘したため。
- AIが判断を使い、直すための記録（どの判断の答えと理由をどう結び付けたか・判断が無かった聞きたい事・未決に当たった聞きたい事）は、評価に書かない。対象者の示唆にならない、と指示者が指摘したため。

## 図

図は mermaid の記法で、` ```mermaid ` のコードブロックに書く。どの章に、何の事実の図を置くかは、下の表に従う。題・形・色・値と軸の見せ方は、図解の中核判断の答えに従い、記法の癖は mermaid の一般的な業務知識に従う。

指示者は、評価を Claude デスクトップアプリのファイル表示で読む。この表示は mermaid の色の指定を反映せず、系列を書いた順に青・橙・緑が当たり、橙が一番目立つ。
